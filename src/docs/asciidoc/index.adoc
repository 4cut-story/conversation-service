= conversation-service API
:doctype: book
:icons: font
:toc: left
:toclevels: 2

대화 녹음 → 전사 → 장면 선택 → 콘티 → 그림 → 4컷 합성. 이 문서는 테스트(Spring REST Docs)가 만든 실제 요청·응답으로 만든다.

* 사용자 API는 web → api-gateway를 거친다. 게이트웨이가 JWT를 검증해 `X-User-Id`를 붙인다. 남의 대화는 404.
* GPU 워커 API(`/internal/gpu-jobs/**`)는 GPU PC의 워커가 게이트웨이를 거쳐 부른다. 게이트웨이가 `GPU_WORKER_TOKEN`을 확인한다.
* 오류는 모두 `{error: {code, message, traceId}}` 형식이다 (docs `api-conventions.md`).

== GPU 워커 API
워커가 작업을 가져가(풀링) 실행한다. 클러스터는 GPU PC를 부르지 않는다. 비어 있으면 2초부터 10초까지 늘려 가며 다시 묻는다.

=== 작업 가져가기

|===
|type |input |result

|TRANSCRIBE
|`{audioUrls: [GET 주소…], language?}`
|`{segments: [{speaker, start, end, text}], language}`

|LLM
|`{model, system, prompt, jsonSchema, options: {num_ctx, temperature, seed}}` — Ollama `format`에 jsonSchema를 넣는다
|`{content: "<모델이 낸 JSON 문자열>", evalCount}`

|IMAGE
|`{images: [{name, prompt, negativePrompt, seed, width, height, uploadUrl}]}` — PNG를 uploadUrl로 PUT
|`{uploaded: [name…]}`
|===
